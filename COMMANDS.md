# Command Cheat Sheet

Run everything from the project root (`Inventoryhub`) with Docker Desktop open.
See [README.md](README.md) for detailed explanations and [Troubleshooting](README.md#18-troubleshooting) for common errors.

| Area               | Command                                                                                                                                                                                                                                                                                                | What it does                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| **Start / stop**   | `npm run db:up`                                                                                                                                                                                                                                                                                        | Start PostgreSQL                                         |
|                    | `npm run dev:backend`                                                                                                                                                                                                                                                                                  | Start API → http://localhost:3000/api/health             |
|                    | `npm run dev:frontend`                                                                                                                                                                                                                                                                                 | Start React → http://localhost:5173                      |
|                    | `npm run db:stop`                                                                                                                                                                                                                                                                                      | Stop PostgreSQL (data kept)                              |
| **Database**       | `npm run db:ps`                                                                                                                                                                                                                                                                                        | Is the database running / healthy?                       |
|                    | `npm run db:logs`                                                                                                                                                                                                                                                                                      | Show database logs                                       |
|                    | `npm run db:down`                                                                                                                                                                                                                                                                                      | Remove container (data kept)                             |
|                    | `npm run prisma:studio --workspace=@inventory/backend`                                                                                                                                                                                                                                                 | Browse and edit data in the browser                      |
|                    | `docker compose exec postgres psql -U inventory -d inventory`                                                                                                                                                                                                                                          | SQL shell                                                |
| **Delete records** | `docker compose exec postgres psql -U inventory -d inventory -c "TRUNCATE users, roles, permissions, user_roles, role_permissions, categories, products, warehouses, inventory_balances, stock_movements, suppliers, purchase_orders, purchase_order_items, sales_orders, sales_order_items CASCADE;"` | Delete all rows, keep tables                             |
|                    | `cd apps/backend` → `npx prisma migrate reset`                                                                                                                                                                                                                                                         | ⚠️ Delete the whole DB and rebuild it (local only)       |
| **Schema changes** | `npm run prisma:validate`                                                                                                                                                                                                                                                                              | Check the schema for errors                              |
|                    | `npm run db:migrate:create -- --name xyz`                                                                                                                                                                                                                                                              | Create a migration without applying it                   |
|                    | `npm run db:migrate:dev`                                                                                                                                                                                                                                                                               | Apply the migration and update the client                |
|                    | `npm run db:migrate:status`                                                                                                                                                                                                                                                                            | See applied and pending migrations                       |
|                    | `npm run db:migrate:deploy`                                                                                                                                                                                                                                                                            | Apply migrations (new machine / server)                  |
|                    | `npm run prisma:generate`                                                                                                                                                                                                                                                                              | Regenerate Prisma types                                  |
| **Code quality**   | `npm run lint`                                                                                                                                                                                                                                                                                         | Find code problems                                       |
|                    | `npm run lint:fix`                                                                                                                                                                                                                                                                                     | Auto-fix code problems                                   |
|                    | `npm run typecheck`                                                                                                                                                                                                                                                                                    | TypeScript errors                                        |
|                    | `npm run format`                                                                                                                                                                                                                                                                                       | Format all files                                         |
|                    | `npm test`                                                                                                                                                                                                                                                                                             | Unit tests                                               |
|                    | `npm run test:e2e`                                                                                                                                                                                                                                                                                     | e2e tests (needs the database)                           |
|                    | `npm run build`                                                                                                                                                                                                                                                                                        | Production build of both apps                            |
| **Backup**         | `docker compose exec postgres pg_dump -U inventory -d inventory -Fc -f /tmp/inventory.dump`                                                                                                                                                                                                            | Create a backup inside the container                     |
|                    | `docker compose cp postgres:/tmp/inventory.dump ./backups/inventory.dump`                                                                                                                                                                                                                              | Copy the backup to your PC                               |
| **Git**            | `git status`                                                                                                                                                                                                                                                                                           | What changed                                             |
|                    | `git add -A` → `git commit -m "msg"`                                                                                                                                                                                                                                                                   | Save changes locally                                     |
|                    | `git push`                                                                                                                                                                                                                                                                                             | Upload to GitHub                                         |
|                    | `git pull`                                                                                                                                                                                                                                                                                             | Download from GitHub                                     |
| **Skills**         | `npx skills experimental_install`                                                                                                                                                                                                                                                                      | Restore AI agent skills from `skills-lock.json` (new PC) |
|                    | `npx skills list`                                                                                                                                                                                                                                                                                      | List installed skills                                    |
|                    | `npx skills update`                                                                                                                                                                                                                                                                                    | Update skills                                            |
| **Fixes**          | `Get-NetTCPConnection -LocalPort 5173` → `Stop-Process -Id <PID>`                                                                                                                                                                                                                                      | Free a busy port                                         |
|                    | `npm install` → `npm run db:migrate:deploy` → `npm run prisma:generate`                                                                                                                                                                                                                                | After `git pull` or on a new PC                          |
